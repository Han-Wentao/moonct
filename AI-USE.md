# AI-use disclosure

Codex provided AI assistance during MoonCT development for design discussion, MoonBit implementation and refactoring, test-case drafting, documentation, duplication research, and protocol-boundary review. The participant directed the project scope. The checks listed in the repository documentation were run in the local workspace; the project maintainer remains responsible for independently reviewing the result and for correctness, security, licensing, and maintenance.

The implementation is not presented as a port of AI-generated or third-party source. Protocol behavior is based on the publicly available RFC 6962 and RFC 9162 specifications. The package does not claim a security audit or provide cryptographic primitives; callers must supply and validate production hash and signature implementations.
